**# TsenaZebu**  
   
**Plateforme web de vente et d'achat de bovins à Madagascar.**  
   
**## Fonctionnalités**  
**- Création de compte et connexion**  
**- Publication d'annonces (photos, prix, localisation)**  
**- Recherche et filtres**  
**- Contact entre acheteur et vendeur**  
   
**## Technologies**  
**React, Next.js, Node.js, MongoDB**  
   
**## Prérequis**  
**- Node.js 18 ou plus**  
**- MongoDB (local ou MongoDB Atlas)**  
**- Git**  
   
**## Installation**  
   
**1. Cloner le dépôt**  
**```bash**  
**   git clone https://github.com/VOTRE-PSEUDO/TsenaZebu.git**  
**   cd TsenaZebu**  
**```**  
   
**2. Installer les dépendances**  
**```bash**  
**   npm install**  
**```**  
   
**3. Configurer les variables d'environnement : copier `.env.example` en `.env`, puis remplir les valeurs**  
**```bash**  
**   cp .env.example .env**  
**```**  
   
**4. Lancer le projet**  
**```bash**  
**   npm run dev**  
**```**  
   
**5. Ouvrir http://localhost:3000**  
   
**## Structure du projet**  
**```**  
**TsenaZebu/**  
**├── app/ ou pages/    # Pages Next.js**  
**├── components/       # Composants React**  
**├── server/           # API Node.js**  
**└── .env.example**  
**```**
